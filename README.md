# Sistem Informasi Perpustakaan

Aplikasi berbasis terminal untuk membantu pengelolaan data perpustakaan, anggota, dan transaksi peminjaman.

## Fitur

- Mengelola data buku dan anggota.
- Mencatat peminjaman, pengembalian, dan perpanjangan masa pinjam.
- Menampilkan riwayat transaksi serta menghitung denda keterlambatan.
- Membuat struk transaksi dan laporan perpustakaan.

## Persyaratan

- Python 3
- Tidak memerlukan dependensi eksternal.

## Menjalankan Aplikasi

Jalankan perintah berikut dari direktori proyek:

```bash
python "sistem perpustakaan.py"
```

## Penyimpanan Data

Data disimpan dalam berkas teks di direktori kerja aplikasi. Sebelum mengunggah proyek ke GitHub, periksa dan hapus data lokal yang berisi informasi pribadi atau kredensial.
